barakobrew · philosophy & resources
01

Philosophy

The site sells; barakoBrew is where people spend eight hours. These rules trade delight for predictability on purpose.

01

Surface the hidden features

Per-field permissions, scheduling, dry runs and audit history already exist in the codebase. If a capability has no visible home in the UI, it does not exist to the user.

02

Show the destructive consequence

Switching tenant re-issues your token. Publishing fires workflows. Every irreversible action states what it will do, in place, before it happens.

03

Density first, breathing room in panels

Tables run at 44px rows with hairline dividers; panels get the padding. Never the other way round.

04

Mono means machine

Slugs, IDs, timestamps, scopes and template variables are always mono, so a human value is never mistaken for a system value.

05

State is always named

Draft, In review, Scheduled, Published, Archived — one chip vocabulary, identical colours everywhere, never a bare colour dot.

06

No modal for real work

Editing happens in place with a right rail. Overlays are for choosing, confirming and previewing only.

02

Layout shell

One shell for every screen: 232px sidebar, sticky 56px toolbar, fluid content, optional 320px rail. New screens fill the shell rather than inventing chrome.

Token Value Where it applies
--app-frame 1440 × 900 Admin canvas. Sidebar 232, content fluid, rail 320.
--row-height 44px Table rows and list items — also the minimum hit target.
--control-height 32px / 36px Sidebar items and toolbar buttons / inputs and selects.
--radius 10px controls · 14px panels Tighter than the marketing site; density reads as tooling.
--pad 12 / 14 / 16 / 24 Cell padding 12–14, panel padding 16–24. Nothing larger.
--divider 1px #E7E8F1 Hairlines instead of shadows for structure.
--popover 0 16px 40px rgba(16,18,35,.16) Tenant switcher, menus, dry-run results. The only elevation.

Status vocabulary

Five states, fixed colours, used identically in tables, editor headers and workflow nodes. Adding a sixth state requires a decision entry.
